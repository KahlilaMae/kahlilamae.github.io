The Business Reason

When the requested model is short on stock, we risk losing the whole order.

Customer service can offer an approved substitute at the quoted price. The order must still meet the minimum profit margin.

This customer needs all 15,000 devices to be the same model. Before making an offer, check whether one approved model can ship in time.

Your perspective

Additional considerations

Consider the options below in your response.

Find more stock
  • Move up an incoming shipment

    Get the requested model to the customer on time.

  • Source from an authorized distributor

    Fill the 6,000-unit gap if the order still meets margin.

  • Reallocate stock from a later order

    Fill the gap if the later order can still ship as agreed.

  • Request priority production

    Ask for 6,000 more units if timing and margin allow.

  • Offer certified refurbished units

    Fill the gap with the same model if the customer accepts refurbished units.

Offer a different model
  • Switch to one approved model

    Offer 15,000 matching units at the quoted price if the order meets margin.

  • Offer a newer model for the full order

    Keep one model and stay on schedule if stock and pricing work.

  • Have the vendor prep and test substitutes

    Ease IT’s workload if the customer accepts two models.

Adjust the rollout
  • Split delivery using the same model

    Ship 9,000 now and 6,000 later if the customer can roll out in phases.

  • Move the rollout date

    Give IT more time to prepare one model.

Cover the gap
  • Use temporary or existing devices

    Keep employees working until the rest arrive.
